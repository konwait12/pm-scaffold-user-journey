# 分叉维度清单（Divergence Checklist）

> 用途：生成前对主链每个节点逐维扫描"这一步的可能性空间"，决定哪些差异**必须展开成分支**、哪些**只需一行声明**。质量 = 维度穷举，不是内容堆砌。
>
> 使用时机：Generate 前必读（SKILL.md §5「分叉维度扫描」）；Audit 时按「维度声明表」复核（SKILL.md §6 v1.4 Audit 新增项）。

## 一、九维扫描表

对主链每个节点逐一过下表。判定三分法：

- **材料支持差异** → 展开为分支路径或独立节点，标注证据位置；
- **材料不支持差异** → 不展开，记入「覆盖与边界」维度声明表（模板见 §三），一行声明完事，禁止逐节点重复九遍；
- **材料没提但业务上高概率存在** → 标 UNKNOWN 挂待确认，禁止编造，禁止写成"不存在"。

| # | 维度 | 扫描问题 | 材料支持差异时的动作 | 实例 |
|---|---|---|---|---|
| 1 | **通道** | 同一节点是否有多个进入/触达通道，且后续步骤可能不同？ | 拆成独立路径分支分别展开，不得合并成笼统节点；每通道单独提取为触点 | 收到预约成功通知：短信进 3 步 vs 邮件进 4 步 vs 服务号进 2 步 |
| 2 | **前置状态** | 节点前置条件是否有多个互斥取值？ | 按取值分叉，或在节点内显式标注差异 | 已注册/未注册；白名单内/外；All users vs InCHANEL client |
| 3 | **数量选择** | 同一动作是否可选全部/部分/无？ | 每个选项给一条后续路径 | 全部创建 / 部分创建 / 不创建；携伴 0 人 / 1 人 / N 人 |
| 4 | **时间边界** | 行为是否受时间窗口约束？ | 按窗口前后分叉；相对时间（D-7/D-1/D）落成时间钩子 | 提前 7 天收到行程单 vs 活动当天才收到 |
| 5 | **结果** | 操作是否可能成功/部分成功/失败/被拒？ | 失败分支显式画出，标注失败后的去向（见维度 9） | 核销成功 vs 核销失败；提交预约成功 vs 被拒 |
| 6 | **角色视角** | 同一业务点是否多个角色都参与（各自视角不同）？ | 每个角色独立节点/泳道，禁止压成混合旅程 | 客人出示核销码、FA 扫码核销、系统校验状态 |
| 7 | **重复/幂等** | 用户是否可能重复触发同一动作？ | 重复路径独立画，说明重复后的结果 | 重复提交预约；对已核销记录再次扫码 |
| 8 | **中断/恢复** | 中途退出后能否再进入？状态是否保留？ | 画恢复路径 + 状态保持语义；无恢复语义要显式声明 | 填表填一半退出，再进入时草稿是否还在 |
| 9 | **终止语义** | 这条分支的终点是死路还是可恢复？ | failure/退出节点显式标注「终止」或「可恢复（回流点）」 | 预约失败可重试（回流） vs 白名单外永久拒绝（终止） |

**边界衔接（外延两问）**：起点之前用户从哪来（前一步），终点之后用户去往哪（后一步）。材料有线索就补；无线索不编，记 UNKNOWN。

## 二、旧清单去向（信息不丢对照）

三套旧检查清单的内容已并入上表，不再单列：

| 旧清单 | 去向 |
|---|---|
| 触达通道矩阵五检查（触发条件/发送时机/内容模板/用户分层/失败兜底） | 维度 1「通道」：每个通道展开时逐项核触发条件、时机、内容模板差异、用户分层、发送失败兜底 |
| 分支完整性自检六项（身份等级/登录态/新老用户/权限/空状态/数据异常） | 维度 2「前置状态」（身份/登录/新老/权限）+ 维度 5「结果」（空状态与数据异常归入失败分支的失败来源） |
| 异常路径触发点五层表（入口/数据/操作/权限/内容） | 维度 5「结果」的失败来源检查表：**入口层**（无权限/链接失效）、**数据层**（空数据/缺失/加载失败）、**操作层**（创建失败/网络异常）、**权限层**（登录过期/多端冲突）、**内容层**（图片加载失败/内容过期）——Audit 时按五层逐个确认异常都有去向 |

## 三、维度声明表模板（写入主文档「覆盖与边界」）

| 维度 | 材料证据 | 声明 |
|---|---|---|
| 通道 | 有：短信 vs 邮件后续不同 | 已拆独立路径（路径 P2/P3），见矩阵 §角色旅程矩阵 |
| 前置状态 | 无 | 材料未区分前置状态，全部节点按单一前置处理 |
| 数量选择 | 有：创建全部/部分 | 见节点 N12/N13 分叉 |
| 时间边界 | 未提及 | UNKNOWN：活动临近时入口是否关闭待确认 |
| 结果 | 有：核销成功/失败 | 失败去向见 N31（可恢复，回流 N28） |
| 角色视角 | 有：FA + 客人 | 双泳道展开 |
| 重复/幂等 | 无 | 材料未提重复操作场景 |
| 中断/恢复 | 未提及 | UNKNOWN：中途退出是否保留草稿待确认 |
| 终止语义 | 有：白名单外拒绝 | N41 终止，无回流 |
| 边界衔接 | 部分 | 起点前一步=线下传单扫码（材料图注），终点后一步 UNKNOWN |

**Audit 判定**：声明表缺行 = 该维没扫（不通过）；整表 10 行齐全但 90% 是 UNKNOWN = 材料确实薄，需在待确认清单挂问题，不算通过也不算失败，回到 Clarify。
