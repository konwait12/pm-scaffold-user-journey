状态流 — 一次 MR 在旅程中的状态迁移，含拖期分支与修改回路。状态命名与 user-journey.md 路径覆盖表一致。

↩ 修改回路：开发者改完 push → 回到「评审中」；「拖期」经逾期升级后同样回到「评审中」。回路对应路径类型 recovery。
